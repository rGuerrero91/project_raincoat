# Similarity Search Guide - Raincoat API

## Overview

Raincoat's similarity search uses **pgvector** with **FashionCLIP embeddings** to find visually and semantically similar clothing items. The system supports advanced filtering by category, colors, materials, and similarity thresholds.

## How It Works

### 1. Vector Embeddings
Each clothing item has a 512-dimensional vector embedding generated by FashionCLIP:
- Captures visual features (color, pattern, texture, shape)
- Encodes semantic meaning (style, formality, occasion)
- Stored in PostgreSQL with pgvector extension

### 2. Similarity Calculation
Uses **cosine distance** to measure similarity:
- `0.0` = Identical items (100% similar)
- `1.0` = Completely different items (0% similar)
- `< 0.2` = Very similar (>80% similarity)
- `0.2-0.5` = Moderately similar (50-80% similarity)
- `> 0.5` = Different (<50% similarity)

### 3. IVFFlat Index
Database uses IVFFlat indexing for fast approximate nearest neighbor search:
- Sub-linear query time
- Scales to thousands of items
- Configured for cosine distance operator (`<=>`)

## API Endpoints

### 1. Find Similar Items by Clothing Piece ID

**Endpoint:** `GET /api/v1/clothing_pieces/:id/similar`

Find items similar to a specific clothing piece in your wardrobe.

**Query Parameters:**
- `limit` (optional, default: 10, max: 50) - Number of results
- `category` (optional) - Filter by category: `tops`, `bottoms`, `shoes`, `outerwear`, `accessories`
- `min_similarity` (optional, 0-100) - Minimum similarity percentage
- `colors` (optional) - Comma-separated color names (e.g., `blue,navy,white`)
- `materials` (optional) - Comma-separated materials (e.g., `cotton,denim`)

**Example Request:**
```bash
# Basic similarity search
curl "http://localhost:3000/api/v1/clothing_pieces/1/similar?limit=10"

# Find similar tops with at least 70% similarity
curl "http://localhost:3000/api/v1/clothing_pieces/1/similar?category=tops&min_similarity=70"

# Find similar items in blue or navy
curl "http://localhost:3000/api/v1/clothing_pieces/1/similar?colors=blue,navy"

# Find similar cotton items
curl "http://localhost:3000/api/v1/clothing_pieces/1/similar?materials=cotton&limit=5"

# Combined filters
curl "http://localhost:3000/api/v1/clothing_pieces/1/similar?category=tops&colors=blue&min_similarity=60&limit=15"
```

### 2. Search by Custom Vector

**Endpoint:** `POST /api/v1/embeddings/search`

Search using a custom 512-dimensional vector (useful for finding items similar to an external image).

**Request Body:**
```json
{
  "vector_data": [0.123, -0.456, 0.789, ...], // 512 numbers
  "limit": 10,
  "category": "tops"
}
```

**Example Request:**
```bash
curl -X POST "http://localhost:3000/api/v1/embeddings/search" \
  -H "Content-Type: application/json" \
  -d '{
    "vector_data": [0.1, 0.2, ...],
    "limit": 5,
    "category": "tops"
  }'
```

**Response:**

## Advanced Usage

### Filtering Strategies

#### 1. Category-Specific Search
Find similar items within the same category (great for finding alternatives):
```bash
# Find similar shoes
curl "http://localhost:3000/api/v1/clothing_pieces/5/similar?category=shoes"
```

#### 2. Cross-Category Search
Find complementary items from different categories (outfit pairing):
```bash
# For a blue shirt, find matching bottoms (don't filter by category)
curl "http://localhost:3000/api/v1/clothing_pieces/1/similar?colors=blue,beige,white"
```

#### 3. High-Precision Search
Only show very similar items:
```bash
# Only items with >85% similarity
curl "http://localhost:3000/api/v1/clothing_pieces/1/similar?min_similarity=85"
```

#### 4. Material-Based Search
Find items with similar fabric characteristics:
```bash
# Find similar cotton items
curl "http://localhost:3000/api/v1/clothing_pieces/1/similar?materials=cotton"

# Find items that work well together (e.g., wool with wool)
curl "http://localhost:3000/api/v1/clothing_pieces/3/similar?materials=wool,merino"
```

#### 5. Color Coordination
Find items in complementary or matching colors:
```bash
# Find navy or blue items to match
curl "http://localhost:3000/api/v1/clothing_pieces/1/similar?colors=navy,blue,indigo"
```

## Frontend Integration

### React/TypeScript Example

```typescript
// services/similaritySearch.ts
interface SimilarityFilters {
  limit?: number;
  category?: string;
  minSimilarity?: number;
  colors?: string[];
  materials?: string[];
}

export async function findSimilarItems(
  clothingPieceId: number,
  filters: SimilarityFilters = {}
): Promise<SimilaritySearchResponse> {
  const params = new URLSearchParams();

  if (filters.limit) params.append('limit', filters.limit.toString());
  if (filters.category) params.append('category', filters.category);
  if (filters.minSimilarity) params.append('min_similarity', filters.minSimilarity.toString());
  if (filters.colors) params.append('colors', filters.colors.join(','));
  if (filters.materials) params.append('materials', filters.materials.join(','));

  const response = await fetch(
    `/api/v1/clothing_pieces/${clothingPieceId}/similar?${params.toString()}`
  );

  return response.json();
}

// Usage in component
const SimilarItemsView: React.FC<{ itemId: number }> = ({ itemId }) => {
  const [similarItems, setSimilarItems] = useState([]);
  const [filters, setFilters] = useState({
    category: 'tops',
    minSimilarity: 70,
    limit: 10
  });

  useEffect(() => {
    findSimilarItems(itemId, filters).then(response => {
      setSimilarItems(response.data.similar_pieces);
    });
  }, [itemId, filters]);

  return (
    <div>
      <h2>Similar Items</h2>
      {similarItems.map(item => (
        <div key={item.piece.id}>
          <p>{item.piece.name}</p>
          <span>{item.similarity_percentage}</span>
        </div>
      ))}
    </div>
  );
};
```

### Native Mobile Example (React Native / Expo)

```typescript
// hooks/useSimilarItems.ts
import { useState, useEffect } from 'react';

export function useSimilarItems(itemId: number, filters = {}) {
  const [similarItems, setSimilarItems] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchSimilar = async () => {
      try {
        setLoading(true);
        const response = await fetch(
          `${API_BASE_URL}/api/v1/clothing_pieces/${itemId}/similar`,
          {
            method: 'GET',
            headers: {
              'Content-Type': 'application/json',
              // Add auth headers if needed
            },
          }
        );

        const data = await response.json();

        if (data.success) {
          setSimilarItems(data.data.similar_pieces);
        } else {
          setError(data.error);
        }
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    };

    if (itemId) {
      fetchSimilar();
    }
  }, [itemId, filters]);

  return { similarItems, loading, error };
}

// Usage in screen
import { useSimilarItems } from './hooks/useSimilarItems';

function ItemDetailScreen({ route }) {
  const { itemId } = route.params;
  const { similarItems, loading } = useSimilarItems(itemId);

  return (
    <View>
      <Text>Similar Items</Text>
      {loading ? (
        <ActivityIndicator />
      ) : (
        <FlatList
          data={similarItems}
          renderItem={({ item }) => (
            <SimilarItemCard
              name={item.piece.name}
              similarity={item.similarity_score}
              image={item.piece.images?.[0]?.url}
            />
          )}
        />
      )}
    </View>
  );
}
```

## Performance Optimization

### Database Indexing
```sql
-- IVFFlat index for fast approximate search
CREATE INDEX ON clothing_embeddings
USING ivfflat (vector_data vector_cosine_ops)
WITH (lists = 100);

-- For larger datasets (>10k items), increase lists parameter:
-- WITH (lists = SQRT(row_count))
```

### Query Optimization Tips
1. **Use category filters** - Reduces search space significantly
2. **Set reasonable limits** - Default 10, max 50 recommended
3. **Cache frequent queries** - Similar items don't change often
4. **Batch operations** - When generating many similarities at once

### Client-Side Caching
```typescript
// Cache similar items for 5 minutes
const CACHE_TTL = 5 * 60 * 1000;
const similarItemsCache = new Map();

function getCachedSimilar(itemId: number) {
  const cached = similarItemsCache.get(itemId);
  if (cached && Date.now() - cached.timestamp < CACHE_TTL) {
    return cached.data;
  }
  return null;
}
```

## Troubleshooting

### No Similar Items Found
**Possible causes:**
1. Item doesn't have an embedding yet
2. `min_similarity` threshold too high
3. Filters too restrictive (no items match all criteria)
4. User only has one item in that category

**Solutions:**
```bash
# Check if item has embedding
curl "http://localhost:3000/api/v1/clothing_pieces/1"
# Look for: "has_embedding": true

# Lower similarity threshold
curl "http://localhost:3000/api/v1/clothing_pieces/1/similar?min_similarity=50"

# Remove filters to see all results
curl "http://localhost:3000/api/v1/clothing_pieces/1/similar?limit=50"
```

### Low Similarity Scores
**Possible causes:**
1. Items genuinely different
2. Mixed model versions (tinyclip vs fashionclip)
3. Poor quality original images

**Solutions:**
- Regenerate embeddings with better images
- Use consistent model version across all items
- Lower `min_similarity` to see more results

### Slow Queries
**Possible causes:**
1. Missing IVFFlat index
2. Too many items without category filtering
3. Large limit values

**Solutions:**
```sql
-- Verify index exists
\d+ clothing_embeddings

-- Should show: ivfflat index on vector_data

-- If missing, create it:
CREATE INDEX clothing_embeddings_vector_idx
ON clothing_embeddings
USING ivfflat (vector_data vector_cosine_ops);
```

## API Error Responses

### No Embedding Available
```json
{
  "success": false,
  "error": "No embedding available for this clothing piece"
}
```
**Solution:** Generate embedding for the item first.

### Invalid Vector Data
```json
{
  "success": false,
  "error": "Invalid vector data. Must be array of 512 numbers or comma-separated string."
}
```
**Solution:** Ensure vector has exactly 512 dimensions.

### Item Not Found
```json
{
  "success": false,
  "error": "Clothing piece not found"
}
```
**Solution:** Verify item ID exists and belongs to current user.
